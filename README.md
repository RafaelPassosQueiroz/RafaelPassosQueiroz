## 🚀 Projetos em destaque

### 📦 Inventra

Plataforma de **gestão de estoque para cozinhas industriais**, desenvolvida com foco na redução de desperdícios e no uso mais eficiente de recursos.

O projeto reúne diferentes áreas da tecnologia em uma única solução:

- **Backend:** Java, Spring Boot e PostgreSQL
- **Frontend:** React e TypeScript
- **Mobile:** Android / Kotlin
- **Dados:** Databricks e arquitetura Bronze → Silver → Gold
- **Business Intelligence:** Qlik Sense
- **Inteligência Artificial:** Python, FastAPI e LangGraph
- **IA e dados não relacionais:** MongoDB

O Inventra me permite trabalhar justamente na interseção entre **engenharia de software, dados, BI e inteligência artificial**.

🔗 [Conheça a organização InventraTech](https://github.com/InventraTech)
